# How Linux Works

How Linux Works, by Brian Ward, explains what the operating system actually does under the hood — the machinery that most users never see. It is written for people comfortable using Linux who want to understand what happens between pressing the power button and getting a shell.

The book follows the system's natural flow: the boot process, the kernel, udev and device management, disks and filesystems, then user space with processes, users and groups, and logging. Later chapters cover networking from interfaces up through the TCP/IP tools you actually use, along with shells, scripting, file sharing, and the basics of desktop environments. Ward consistently shows the real files and commands — /proc, /etc, systemd, cron — rather than abstract descriptions.

What sets it apart is its practical curiosity: every chapter answers "why" as well as "how". Read it and debugging stops being guesswork. It remains one of the best single-volume explanations of Linux for developers and administrators alike.
