# Fluent Python

Fluent Python, 2nd edition by Luciano Ramalho, is the definitive guide to writing Python the way it is meant to be written — idiomatically, taking full advantage of the language's data model rather than translating habits from other languages.

The book works systematically through the features that make Python Python: sequences, dictionaries and sets, strings and the bytes/text divide, first-class functions, type hints and protocols, decorators and closures, generators and iterables, descriptors, and classes done well. The second edition, updated for modern Python, adds substantial coverage of typing, data classes, and async/await, and concludes with concurrency using threads, processes, and asyncio, plus a section on dynamic attributes and metaprogramming.

Ramalho's approach teaches by contrast: showing the naive way, then the fluent way, and explaining the machinery underneath each. It is long and dense, best read across a few weeks of practice. For intermediate Python developers, it is the single highest-leverage book on the language.
