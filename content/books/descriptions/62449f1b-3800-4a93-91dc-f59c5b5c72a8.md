# The C++ Programming Language, 4th Edition

The C++ Programming Language, 4th edition, is Bjarne Stroustrup's comprehensive reference for C++ as defined by the C++11 standard. Written by the language's creator, it is the definitive description of both the language and its standard library in one volume.

The book is divided into four parts: an orientation to the language's core ideas, the complete language rules from declarations through templates, the standard library including containers, algorithms, strings, streams, and regular expressions, and a final part on design philosophies and concurrency support. Coverage is exhaustive and precise, with thousands of short examples rather than long projects.

Be clear about what it is: a reference and a deep study text, not a beginner's tutorial. Nobody reads it front to back on day one — but everyone who works seriously in C++ ends up consulting it for years. When you need the authoritative answer to "what does C++ actually guarantee here", it is this book.
