# The Little Redis Book

The Little Redis Book, by Karl Seguin, is a free, compact introduction to Redis — the in-memory data structure store that became a staple of modern web infrastructure. At around thirty pages, it is the fastest serious way to understand what Redis is and when to reach for it.

The book opens with the key-value mindset and how Redis differs from plain caches like Memcached, then works through its data structures one by one: strings, lists, sets, hashes, and sorted sets, each with the commands and real-world use cases they unlock — counters, queues, leaderboards, and indexes. Later chapters cover querying, memory management, persistence, and the basics of scaling with replication.

Seguin's examples are concrete and command-line first, so you can follow along with a running Redis instance in a terminal. It will not replace the official documentation for advanced deployment, and it doesn't try to. Read it to build the right mental model, then keep it as a quick reference.
